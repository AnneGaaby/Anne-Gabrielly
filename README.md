# Portfolio — Anne Gabrielly Alves

Portfolio professionnel statique d'Anne Gabrielly Alves, profil junior en informatique à Clarens, Vaud. Il présente un positionnement polyvalent couvrant l'IT Support, les systèmes, le hardware et le développement Web.

## Technologies

- HTML5 sémantique
- CSS3 responsive
- JavaScript natif
- Polices Cormorant Garamond et Jost (chargées depuis Google Fonts avec des polices système de secours)

Aucun framework, script de suivi, cookie non nécessaire, mot de passe, token ou clé API n'est utilisé.

## Ouvrir le site localement

Ouvrez simplement `index.html` dans un navigateur moderne.

Pour tester le site via un serveur local, depuis le dossier `portfolio`, lancez :

```powershell
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000` dans votre navigateur.

## Publication

Le dossier peut être publié tel quel sur GitHub Pages, Netlify ou Cloudflare Pages. Vérifiez l'URL finale avant de partager le portfolio afin que les aperçus Open Graph puissent éventuellement être complétés avec une URL et une image de partage réelles.
